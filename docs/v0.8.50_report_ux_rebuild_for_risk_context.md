# v0.8.50 Report UX Rebuild for Risk Context

## Purpose

v0.8.50 reorganizes the top report experience so readers can distinguish:

- core decision output,
- supplemental risk context,
- global risk-line detail,
- domestic / FX / rate context,
- data limitations,
- source acquisition status.

This is a report UX change only.

## Display Boundary

The standard HTML report now adds a "判断とリスク文脈の読み分け" hub below the first-read summary and buy decision card.

The hub separates:

- `本体判断`: `final_action` and buy readiness display value from the buy decision card.
- `補助判断`: Japan-resident integrated context, domestic context, FX context, and rate context.
- `グローバル危険ライン`: core risk-line stage and composite stress score.
- `データ制約・取得状況`: macro limitations and acquisition status counts.

## Non-Impact Boundary

v0.8.50 does not change:

- `final_action`
- `buy_readiness_score`
- threshold JSON
- reliability policy
- buy blocker logic
- buy decision card logic
- buy window / candidate thresholds
- risk label definitions
- CI, scripts, or dependencies

## Deferred

The following are intentionally deferred:

- Full report page redesign.
- New scoring or weighting.
- Connecting supplemental context to final decisions.
- Making actual-smoke or live acquisition mandatory.

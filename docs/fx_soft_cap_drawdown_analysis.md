# fx_soft_cap drawdown analysis

`fx_soft_cap_drawdown_analysis` は、historical replay で残った deep drawdown ケースを特定する診断です。

見る項目:

- 13w max drawdown
- 13w forward return / excess return
- VIX level / change
- HYG/LQD credit proxy
- ACWI/SPY relative trend
- USDJPY change
- oil family change
- FX flags

この分析は deep DD を避ける guard 候補を作るための材料です。final action には影響しません。

# v0.8.55 RC Semantics Polish

## Purpose

v0.8.55 fixes remaining report-semantics issues found in the v0.8.54 diagnostic review. The goal is to make display-only context easier to interpret without changing production decisions.

## Changes

- `domestic_danger_context` now exposes:
  - `domestic_asset_level`
  - `domestic_fx_level`
  - `domestic_macro_level`
- `japan_resident_integrated_context` reads domestic asset level separately from FX level.
- EURJPY caution now contributes to integrated `fx_risk_level`.
- Neutral USDJPY remains normal only when no domestic FX row is stronger.
- `GLD` unavailable rows are no longer added to domestic danger context. JPY gold is represented by `1540.T`; USD gold remains available in non-domestic candidate/report sections.
- `decision_boundary_experiment` now exposes:
  - `raw_score_delta`
  - `clamped_score_delta`
  - `clamp_reason`
- Multi-asset Japan-resident display now uses `確認材料スコア` instead of `文脈スコア`.
- The diagnostic bundle now includes `project/chatgpt_diagnostic_bundle.py`, its tests, and v0.8.54/v0.8.55 docs.

## Boundaries

No changes were made to:

- `final_action`
- production `buy_readiness_score`
- threshold JSON contents
- reliability policy
- buy blocker/card logic
- risk label definitions
- CI, scripts, or dependencies
- new data source behavior

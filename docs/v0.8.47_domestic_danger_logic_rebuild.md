# v0.8.47 Domestic Danger Logic Rebuild

## Goal

Rebuild the supplemental domestic danger context so it uses observed domestic market metrics instead of acquisition status. The section remains display-only and does not feed equity decision logic.

## Boundary

- `final_action` is unchanged.
- `buy_readiness_score` is unchanged.
- Threshold JSON and reliability policy are unchanged.
- Buy blocker, buy decision card, and buy window/candidate thresholds are unchanged.
- Public Equity Investing context is used only as workflow-supporting design input. Normal app startup and report generation must keep working with Python-only local code and must not require plugins, connectors, or external market-data tools.

## Level Policy

The display layer uses only these domestic danger levels:

- `normal`: observed domestic context is available and not showing a supplemental warning.
- `watch`: observed metrics suggest a follow-up check, but not a hard caution.
- `caution`: observed price weakness plus relevant domestic context is strong enough for a supplemental caution.
- `unavailable`: the required source is missing, unresolved, or only represented by acquisition status.

Missing CPI, BOJ, JGB, Japan REIT, JPY bond, FX, or JPY gold data is treated as a limitation, not as a risk signal.

## Rebuilt Logic

- Domestic equities use Japan equity price metrics such as `1306.T` / `1321.T`.
- JPY bonds use JPY bond proxy price metrics such as `2510.T` plus domestic rate pressure.
- Japan REIT uses Japan REIT proxy price metrics such as `1343.T` plus domestic rate pressure.
- JPY gold uses `1540.T` separately from USD/global gold references such as `GLD` and `GC=F`.
- FX context uses `USDJPY=X` and `EURJPY=X` when observed metrics are available.
- JGB yield curve can create `watch` when the 10-year yield is elevated, but JGB level alone does not create `caution`.
- CPI and BOJ source availability is displayed as observed context or limitation and does not create watch/caution by itself.

## Report Output

The report now carries a `domestic_metric_summary` and per-row fields for:

- asset group
- label
- source status
- metrics used
- limitations

The domestic danger table displays per-row metric limitations, so sample-only or partially available local runs show `price_metrics_missing` or source limitations explicitly instead of implying a risk conclusion.

## Validation Scope

The v0.8.47 validation focuses on targeted tests for domestic danger context, domestic market metrics, report rendering, multi-asset candidates, and Japan-resident context. Full release validation, remote sync, and security publication checks are deferred until a tag/push/release handoff.

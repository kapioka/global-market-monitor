# v0.8.49 Japan Resident Integrated Risk Context

## Purpose

v0.8.49 adds a display-only integrated risk context for Japan residents. It combines existing supplemental context without changing investment decision logic.

The context is intended to show, in one place:

- US/global risk-line state.
- Risk-line confidence audit scope and DXY role.
- Domestic danger context.
- Japan-resident FX context.
- Domestic rate context.
- CPI / BOJ / JGB data limitations.

## Output

The report payload adds:

```text
japan_resident_integrated_risk_context
```

Main fields:

- `global_risk_level`
- `domestic_risk_level`
- `fx_risk_level`
- `rate_risk_level`
- `inflation_data_quality`
- `combined_context_level`
- `primary_reasons`
- `watch_items`
- `data_limitations`
- `source_sections`
- `must_not_affect_final_action`
- `must_not_affect_buy_readiness_score`

## Inputs

The integrated context reads existing payloads only:

- `risk_lines`
- `risk_line_confidence_audit`
- `domestic_danger_context`
- `japan_risk`
- `japan_resident_context`
- `domestic_market_metrics`

It does not fetch new data and does not introduce a new score.

## DXY and JPY FX Separation

`DX-Y.NYB` remains the US/global dollar stress input inside risk-line monitoring.

`USDJPY=X` and `EURJPY=X` remain Japan-resident FX context inputs for checking the yen translation impact of foreign-currency assets.

The integrated context displays both roles together so the report does not imply that DXY and USDJPY/EURJPY are interchangeable signals.

## Data Limitations

Missing CPI, BOJ short-rate, or MOF JGB yield context is shown as a data limitation. Missing Japan-oriented macro data is not converted into a risk signal by itself.

The report continues to distinguish:

- observed market risk,
- supplemental domestic context,
- data unavailable / manual source missing limitations.

## Non-Impact Boundaries

v0.8.49 does not change:

- `final_action`
- `buy_readiness_score`
- threshold JSON
- reliability policy
- buy blocker logic
- buy decision card logic
- buy window / candidate thresholds
- risk label definitions
- CI, scripts, or dependencies

The integrated context includes explicit non-impact flags:

- `must_not_affect_final_action: true`
- `must_not_affect_buy_readiness_score: true`

## Report Display

Markdown, standard HTML, and supplemental dashboard HTML now show the integrated context near the risk-line and domestic context sections.

The display is supplemental and uses non-advice wording. It is meant to help compare domestic, global, FX, rate, and data-limitation context before reading asset-class candidates.

## Deferred

The following are intentionally deferred:

- Connecting the integrated context to `final_action`.
- Connecting the integrated context to `buy_readiness_score`.
- Changing threshold JSON.
- Changing reliability policy.
- Adding live data requirements.
- Making Japan macro acquisition mandatory.

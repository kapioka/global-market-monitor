# v0.8.54 Diagnostic Bundle Completeness Polish

## Purpose

v0.8.54 makes the ChatGPT logic-review diagnostic bundle reproducible and more complete before the next RC validation pass.

The bundle is a local review artifact only. It is not a release package and is not committed.

## Command

```powershell
python -m project.chatgpt_diagnostic_bundle --version v0.8.54
```

Default output:

```text
project/diagnostics/chatgpt_logic_review_v0.8.54.zip
```

## Inclusion Policy

The builder includes:

- explicit review seed files for pipeline, report, domestic context, global risk confidence, Japan-resident integrated context, decision-boundary experiment, buy decision references, and current docs;
- transitive `project.*` Python imports reachable from the seed Python files;
- threshold JSON for review only;
- `indicators.py`, threshold metadata/certainty helpers, scoring, asset comparison, and existing monitor dependencies;
- latest `report.md`, `report.html`, and `supplement_dashboard.html` if present.

## Exclusion Policy

The builder excludes:

- `.git`;
- `.tmp`;
- `project/cache`;
- `project/diagnostics`;
- `project/manual_sources`;
- `project/reports/history`;
- `release`;
- previous diagnostic bundles and expanded diagnostic folders;
- local secrets or release zips.

## Guardrails

- The builder does not change production logic.
- Threshold JSON is copied into the zip for review but not modified.
- `logic_review_questions.md` is sanitized and checked for control characters before the zip is accepted.
- Manifest contents are generated from the actual included file list.

## Validation

Local checks used:

- `python -m pytest project\tests\test_chatgpt_diagnostic_bundle.py`
- `python -m ruff check .`
- `python -m black --check .`
- `git diff --check`

Full pytest, mypy, actual-smoke, and security audit remain deferred to the next RC validation pass.

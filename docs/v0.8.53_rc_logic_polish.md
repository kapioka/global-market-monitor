# v0.8.53 RC Logic Polish

## Purpose

v0.8.53 addresses local RC review findings from the v0.8.52 diagnostic bundle. The changes are limited to supplemental domestic/Japan-resident context quality and report clarity.

This version does not change the production decision boundary.

## Fixed

- `1540.T` JPY gold metrics can now populate the domestic danger context directly from `domestic_market_metrics` even when the multi-asset candidate row is absent or only a fallback row exists.
- `1540.T` wording now describes JPY gold proxy context, while `GLD` / `GC=F` wording describes USD-denominated gold reference context.
- Domestic market metrics now flag suspicious split-like discontinuities as `split_or_discontinuity_suspected`.
- Suspicious price series keep reference display fields but set `risk_signal_allowed` to `False`, forcing the supplemental risk level to `unavailable` instead of watch/caution.
- Drawdown is split into `max_drawdown_12w`, `max_drawdown_26w`, and `max_drawdown_full`.
- The active supplemental price-risk path uses the short lookback drawdown while the full-period drawdown remains a reference field.
- Japan-resident integrated FX context now treats a neutral USDJPY summary as `normal` instead of raising it to caution through generic `moderate` normalization.
- Domestic context metadata now separates observed price metrics, macro values, and fallback/limitation-only rows.

## Boundaries

No changes were made to:

- `final_action`
- production `buy_readiness_score`
- threshold JSON
- reliability policy
- buy blocker or buy decision card logic
- risk label definitions
- CI, scripts, or dependencies
- generated reports, cache, manual source files, release zips, tags, push, or GitHub Release

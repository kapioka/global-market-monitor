# v0.8.44 Domestic Danger Monitoring and RC Validation

This checkpoint adds domestic/Japan-resident market context to supplemental
display surfaces only. It does not change `final_action`, `buy_readiness_score`,
threshold JSON, reliability policy, buy blocker logic, or buy decision card
logic.

## Audit Summary

- Core danger-line judgement is computed by `project/risk_lines.py`.
- The core danger-line input set is global: SPY, HYG, LQD, HYG/LQD, VIX, MOVE,
  oil, dollar index, and US 10Y rates.
- Domestic/Japan-resident values were already available in display-oriented
  payloads such as `multi_asset_candidates`, `japan_risk`, official macro
  context, and acquisition logs.
- Those domestic values did not participate in the core danger-line judgement.
- v0.8.44 keeps the core judgement unchanged and adds a separate supplemental
  `domestic_danger_context`.

## Domestic Danger Context

The new supplemental context reports:

- `domestic_danger_level`
- `domestic_danger_reasons`
- `domestic_watch_items`
- `domestic_data_limitations`
- `uses_domestic_values`
- `must_not_affect_final_action`
- `must_not_affect_buy_readiness_score`

Allowed levels are `normal`, `watch`, `caution`, and `unavailable`.

## Display Integration

The supplemental report now includes domestic context in:

- supplemental market monitoring
- supplemental judgement
- danger-line monitoring
- danger-line detail

Domestic groups remain separated:

- domestic equities: `1306.T`, `1321.T`, and Japan equity references
- JPY bonds: `2510.T`
- Japan REIT: `1343.T`
- JPY gold: `1540.T`
- FX: `USDJPY=X`, `EURJPY=X`
- official macro context: MOF JGB yield curve when available
- limitations: CPI/BOJ missing or unresolved states
- foreign bond references remain separate: `AGG`, `TIP`, `LQD`, `HYG`

## Boundary

Domestic danger context is supplemental and display-only. If domestic context
should ever affect `final_action`, that must be a separate explicit goal with
threshold and reliability policy review.

## Buy Readiness Finding

`buy_readiness_score` is not fixed at 40. The current actual-smoke payload
calculated 40 because the inputs were:

- `market_raw_action: watch`
- `risk_adjusted_action: watch`
- `final_action: watch`
- `risk_stage: normal`
- `data_reliability.level: high`
- `recovery_evidence.grade: building`
- primary blocker: `fx_risk` with `caution` severity
- secondary blocker: `score_shortfall`
- total score below the configured buy threshold: about `0.59 < 0.65`

The score path is therefore an expected conservative watch-state calculation:
positive market/reliability/recovery inputs are offset by FX caution and score
shortfall. It is not a report-rendering constant and not caused by
Japan-resident macro data.

## Japan-Resident Context Boundary

Japan-resident context remains display-only:

- `multi_asset_candidates.affects_buy_readiness_score` is `false`.
- Candidate rows carry `japan_resident_must_not_affect_buy_readiness_score`.
- Official macro values that are `ok` or `partial` can influence domestic-rate
  display/context components.
- Fallback statuses such as `manual_file_missing` and `endpoint_not_resolved`
  remain non-data and give no score boost.
- No Japan-resident context field is read by `build_buy_readiness_score()`.
